 Gym Life Simulator

A 2D pixel-style **Life and Bodybuilding Simulation** game developed using Python and the Pygame library. The project features dynamic scene transitions, mini-game-based workout mechanics, and a functional shop/inventory system.

 Key Features

* **Advanced Economy & Rent System:** Freelance software development mechanic to earn money, along with a rent system that requires payment every 7 days.
* **QTE (Quick Time Event) Workout System:** Hit the `SPACE` bar with perfect timing on gym machines for extra muscle gains—or risk getting injured, which drops energy to zero!
* **Permanent & Consumable Inventory:** Purchase items like an Orthopedic Bed (increases Max Energy), Sports Shoes (increases movement speed), or consumables like Creatine and Chicken & Rice for an instant energy boost.
* **Appearance Change:** Interact with the wardrobe at home to toggle your character's sprite between normal and muscular versions.



 Technologies Used

* **Language:** Python 3.x
* **Library:** Pygame
* **Modules:** `os`, `sys`, `random`



  Game Controls

| Key | Function |
| :--- | :--- |
| **Arrow Keys** | Character Movement |
| **E Key** | Interact (Sleep, Work, Buy, Change Clothes) |
| **I Key** | Open / Close Inventory |
| **1 - 4 Keys** | Consume Items in Inventory |
| **SPACE** | QTE Timing (While Working Out) |
| **H Key** | Hide / Show HUD (UI) |
